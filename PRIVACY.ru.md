# Политика конфиденциальности

*Действует с 30 сентября 2026 года · [English](PRIVACY.md)*

Island — приложение для Mac, которое целиком работает на твоём Mac. В нём нет аккаунта, своего
сервера, аналитики, отчётов о сбоях и рекламы. Никто, включая разработчика, не получает никаких
сведений о тебе и о том, как ты им пользуешься.

## Куда Island подключается

Island выходит в интернет только в этих случаях и только напрямую, без собственного сервера:

- **Spotify, если ты его подключишь.** Island входит в Spotify с твоим собственным ключом
  приложения (Client ID) и использует Spotify Web API для очереди, плейлистов, поиска, лайков и
  повтора. Обложки треков Spotify тоже приходят от Spotify. Что Spotify делает с этими данными,
  описано в [его политике конфиденциальности](https://www.spotify.com/legal/privacy-policy/).
- **Сайты, которые ты сохранил как ссылки.** Чтобы показать значок ссылки, Island один раз
  запрашивает его у самого сайта (`apple-touch-icon.png` или `favicon.ico`) и сохраняет. Сайт
  видит запрос с твоего Mac — так же, как если бы ты открыл его в браузере.

Больше никуда. Island не проверяет обновления и ничего не загружает из интернета сам по себе.

## Что хранится на твоём Mac

| Что | Где | Сколько |
| --- | --- | --- |
| История буфера обмена | только в памяти | до выхода из Island; на диск не пишется |
| Заметки | `~/Library/Application Support/DynamicIsland/notes.txt` | пока не удалишь |
| Голосовые заметки | `~/Library/Application Support/DynamicIsland/Recordings` | пока не удалишь |
| Полка | полка только помнит, где лежат твои файлы; картинки и архивы, которые она делает сама, лежат в `…/DynamicIsland/Shelf` | пока не уберёшь их с полки |
| Вход в Spotify | `…/DynamicIsland/spotify-token.json`, доступен только твоему пользователю | пока не отключишь Spotify |
| Чаты, ссылки, созвоны, настройки | настройки приложения (`com.andrei.dynamicisland`) | пока не удалишь |
| Значки ссылок | `~/Library/Caches/DynamicIsland/Favicons` | кэш, можно удалить в любой момент |

История буфера обмена пропускает всё, что приложения помечают как секретное или временное,
например пароли из менеджеров паролей, и её можно выключить в настройках. Картинки, которые ты
перетаскиваешь из истории, записываются во временную папку, которая очищается при запуске и
выходе из Island.

## Что Island читает и зачем

Всё это используется только на твоём Mac и только когда ты пользуешься функцией. macOS сначала
спрашивает разрешение, и его можно отозвать в любой момент в Системных настройках →
Конфиденциальность и безопасность.

- **Календари.** События на неделю вперёд, чтобы показывать созвоны и напоминать о них. События
  только читаются: не меняются и никуда не отправляются.
- **Микрофон.** Только пока ты записываешь голосовую заметку.
- **Запись системного звука.** Только если включить эквалайзер в такт музыке (по умолчанию
  выключен): звук играющего музыкального приложения раскладывается на уровни для столбиков на
  острове — в памяти, без записи и сохранения.
- **Автоматизация (Spotify, Музыка).** Чтобы управлять воспроизведением и видеть, что играет.
- **Универсальный доступ.** Для среднего клика тремя пальцами: Island следит за касаниями
  трекпада, чтобы распознать жест, и отправляет средний клик. Касания и клики не сохраняются.
- **Буфер обмена.** Для истории буфера обмена, как описано выше.

Перевод текста из буфера делает встроенный в macOS переводчик прямо на устройстве, так что
текст тоже не покидает твой Mac.

## Как удалить свои данные

Закрой Island и удали приложение, затем выполни:

```sh
rm -rf ~/Library/Application\ Support/DynamicIsland ~/Library/Caches/DynamicIsland
defaults delete com.andrei.dynamicisland
```

Чтобы заодно отозвать доступ у Spotify, удали приложение на
[spotify.com/account/apps](https://www.spotify.com/account/apps/).
