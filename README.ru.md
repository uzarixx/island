## Возможности

**Музыка.** Управляет Spotify и Apple Music — тем, что сейчас играет: обложка, перемотка,
громкость, перемешивание, повтор, лайки и избранное. Подключи Spotify, и появятся ещё очередь,
твои плейлисты и поиск; выбери песню внутри плейлиста, и он заиграет с неё. Эквалайзер берёт
цвета из обложки и может двигаться в такт настоящему звуку.

**Полка.** Потащи файлы к чёлке, и она откроется сразу на полке. Пусть лежат, пока не понадобятся:
забери по одному или все разом, отправь по AirDrop, сожми в ZIP, посмотри через Quick Look.
Скриншот или что угодно из буфера обмена вставляется через <kbd>⌘</kbd><kbd>V</kbd>.

<p align="center"><img src="docs/images/shelf.png" alt="Полка" width="80%"></p>

**Созвоны.** События из Календаря (iCloud, Google, Exchange), ссылка на Zoom, Meet, Teams или
Телемост находится сама. Напоминание уведомлением или будильником, который откроет чёлку даже в
режиме «Не беспокоить».

<p align="center"><img src="docs/images/meetings.png" alt="Созвоны" width="80%"></p>

**Живые активности.** Закрытая чёлка показывает, что происходит.

<p align="center"><img src="docs/images/states.png" alt="Состояния закрытой чёлки" width="80%"></p>

**А ещё**
- История буфера обмена, только в памяти, с переводом прямо на устройстве
- Заметки и голосовые заметки
- Быстрый запуск чатов (Telegram, WhatsApp, iMessage) и ссылок
- Ограничение заряда батареи через [batt](https://github.com/charlie0129/batt)
- Пипетка для цвета с любого места экрана, средний клик тремя пальцами на трекпаде
- Управление с клавиатуры: <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Пробел</kbd> открывает остров, цифры
  переключают вкладки
- Русский и английский: по системе или на выбор в настройках

## Установка

1. Скачай последний `Island-<версия>.dmg` из [Releases](../../releases/latest) и перетащи Island в «Программы».
2. Приложение пока не нотаризовано, поэтому при первом запуске macOS его остановит. Открой
   **Системные настройки → Конфиденциальность и безопасность** и нажми **«Всё равно открыть»**.

Нужна macOS 14 Sonoma или новее. Лучше всего работает на MacBook с чёлкой; на других экранах
остров располагается вверху строки меню.

## Spotify

Island управляет приложением Spotify напрямую, как и Apple Music. Очередь, плейлисты, поиск и лайки работают через
Spotify Web API с твоим собственным ключом:

1. Создай приложение на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard).
2. Добавь Redirect URI `http://127.0.0.1:43821/callback` и включи Web API.
3. Вставь Client ID в настройках Island и подключись.

## Приватность

Всё остаётся на твоём Mac. Island обращается только к Spotify, если ты его подключил, и к сайтам
из сохранённых ссылок, чтобы загрузить их иконки. Каждое разрешение спрашивается, только когда
пользуешься функцией, которой оно нужно:

| Разрешение | Зачем |
| --- | --- |
| Универсальный доступ | средний клик тремя пальцами |
| Автоматизация → Spotify, Музыка | управление воспроизведением |
| Календари | созвоны из Календаря |
| Микрофон | голосовые заметки |
| Запись системного звука | эквалайзер в такт музыке (по умолчанию выключен, только музыкальное приложение, ничего не записывается) |

Подробности и как удалить всё, что хранит Island: [политика конфиденциальности](PRIVACY.ru.md).

## Сборка из исходников

Нужны Xcode Command Line Tools (`xcode-select --install`).

```sh
scripts/create-signing-identity.sh   # один раз: разрешения не слетают после пересборки
scripts/build.sh --run               # build/Island.app и запуск
scripts/make-dmg.sh                  # build/Island-<версия>.dmg для Apple Silicon и Intel
scripts/make-dmg.sh minor            # то же, но сначала поднять версию (или patch, major, 1.2.0)
scripts/version.sh                   # текущая версия
```

При смене версии раздел Unreleased в [CHANGELOG.md](CHANGELOG.md) становится разделом этой версии.
